# Springboot Rest API

This is a simple Springboot Rest API application that demonstrates the use of Springboot framework to create RESTful web services. The application provides endpoints for basic CRUD operations, and it is built using Gradle as the build tool. The application also includes Docker Compose support for running a PostgreSQL database and Apache Kafka as dependencies.


To build and run the application, you can use the following commands:
```bash
gradle build
gradle bootRun
```
